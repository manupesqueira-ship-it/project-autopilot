# Project Autopilot

Sistema multi-agente de control plane para orquestar builders externos
(Claude Code, Cursor, Codex) en proyectos de software.

## Documentación

- `MASTER_PLAN.md` — plan maestro de desarrollo
- `docs/` — runbooks, policies, threat models, standards
- `core/` — código del orquestador (Python)
- `projects/` — configuración por proyecto

## Proyectos actuales

- `mira` — virtual try-on app (Next.js)

## Estado

V1 en desarrollo. Ver MASTER_PLAN.md para roadmap.
