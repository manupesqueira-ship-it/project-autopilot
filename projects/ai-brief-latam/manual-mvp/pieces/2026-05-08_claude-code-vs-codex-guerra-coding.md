## 1. Brief Interno

### Tema
La guerra por el coding AI se definió en las últimas semanas. Claude Code (Anthropic) y Codex (OpenAI) son los dos agentes de coding dominantes. Claude Code alcanzó $2.5B de run-rate en febrero 2026 con crecimiento de 10x en 3 meses. Codex tiene 4 millones de devs semanales y ahora corre sobre GPT-5.5. Los dos pueden leer tu codebase completo, hacer cambios multi-archivo, correr tests e iterar. Stripe migró 10,000 líneas de Scala a Java en 4 días con Claude Code — trabajo estimado en 10 semanas de ingenieros.

### Qué pasó
- Claude Code: lanzado febrero 2025, GA mayo 2025, $2.5B run-rate febrero 2026 (Reuters). Stripe lo desplegó en 1,370 ingenieros. Disponible en terminal, IDE, desktop, browser.
- Codex: relanzado con GPT-5.5, 4M devs semanales, 90+ plugins nuevos (Atlassian, GitLab, CircleCI, etc.), worktrees y cloud environments para agentes en paralelo.
- Ambos: leen codebase completo, planifican approach multi-archivo, ejecutan cambios, corren tests, iteran sobre failures.
- La diferencia: Claude Code es más agentic/terminal-first. Codex es más platform/ecosystem-first.

### Por qué importa
1. Si sos dev o founder en LATAM, esta decisión afecta tu productividad diaria
2. La migración de Stripe (10,000 líneas en 4 días vs 10 semanas) es el benchmark más concreto publicado
3. No es "chatbot que escribe código" — son agentes que leen, planean, ejecutan y verifican

### Qué cambia
- ANTES: AI coding = autocompletar líneas, sugerir snippets (Copilot v1, 2022-2024)
- DESPUÉS: AI coding = agentes que leen tu codebase entero, hacen cambios multi-archivo, corren tests, y commiten

### Quién gana / pierde
- **Gana:** Developers de todos los niveles, founders que necesitan mover rápido, equipos chicos
- **Pierde:** Empresas de outsourcing de código básico, devs que no adopten las herramientas
- **Neutro:** GitHub Copilot (sigue existiendo pero la conversación se movió a agentes)

### Datos duros verificables
- Claude Code $2.5B run-rate, crecimiento 10x en 3 meses (Reuters vía GetPanto — confirmado)
- Stripe: 1,370 ingenieros usando Claude Code, migración 10K líneas Scala→Java en 4 días vs 10 semanas estimadas (Anthropic/GetPanto — confirmado)
- Codex: 4M desarrolladores semanales (OpenAI — confirmado)
- GPT-5.5 powering Codex (OpenAI blog — confirmado)
- 90+ plugins nuevos para Codex (OpenAI — confirmado)
- Claude Code disponible en terminal, IDE, desktop, browser (Anthropic — confirmado)
- Codex con worktrees y cloud environments (OpenAI — confirmado)

### Ángulo LATAM
Para founders y devs en LATAM, la elección entre Claude Code y Codex no es trivial. Con equipos más chicos que los de Silicon Valley, la productividad de estas herramientas tiene impacto desproporcionado. Un equipo de 3 devs en CDMX o Bogotá con Claude Code puede producir como uno de 10 sin AI. La barrera de entrada a construir software se está colapsando — y LATAM, con su creciente pool de talento tech, está en posición de beneficiarse más que la mayoría.
