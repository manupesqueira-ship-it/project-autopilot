# Deep Research Protocol

Deep research is used only for decisions with high cost, security, privacy, vendor, architecture, or strategic impact.

## Approval

Deep research requires explicit human approval before it runs.

## Expected Output

- Decision summary.
- Options compared.
- Current primary-source citations.
- Cost and budget impact.
- Security/privacy/compliance risks.
- Implementation implications.
- Recommendation.
- Open questions and decision owner.

## Prohibited

- No invented citations.
- No stale assumptions where current facts matter.
- No paid API calls without approval.
- No implementation work hidden inside a research task.
